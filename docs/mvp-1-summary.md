# MVP 1 Summary

MVP 1 extends MVP 0 with the following features:

- Test/form-style quiz format
- Question generation parameters
- Question regeneration
- Attendance and roster CSV export
- Configurable scoring
- Multiple-answer questions
- No-time-limit questions
- Updated visual identity and UX
- Dockerized application setup

These changes improve teacher control, student participation tracking, question flexibility, user experience, and deployment reliability.
